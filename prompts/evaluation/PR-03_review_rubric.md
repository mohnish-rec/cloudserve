# PR-03 · Review rubric (human review by two people; AI as an extra check only)

- **Version:** 4 (17 Nov 2026); versions 2 retired and 3 removed
- **Category:** Evaluation
- **Serves:** Evaluation Framework: hallucination rate (human review, at least fifty responses, two assessors), customer-satisfaction proxy, citation accuracy
- **Used by:** `scripts/make_review_sheet.py` (the sheets both human assessors fill in). An AI check using the same words was run in development as an extra check only.
- **17 Nov 2026, the course team:** "If the requirement specifies two human reviewers, an AI model cannot replace the second person. You may use AI for additional checks, but it should not count as a human review." Both assessors are people; the AI check is never counted as one of them.
- **Text:** lives in `scripts/review_rubric.py`, so the sheets and any extra AI check always use the same words.
